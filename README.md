# 編集する項目

## プロフィール：index.html

- 所属（学校名・学科）
- 卒業予定年月
- Email
- 紹介文・趣味（必要に応じて修正）

`<!-- 学校名・学科を記入 -->` などのコメントを自分の内容に置き換えてください。開発環境はプロフィールには掲載せず、各作品ページで編集します。

## 作品カード：index.html と works.html

- 正式な作品タイトル（個人制作作品は現在仮の説明名）
- 静止画
- プレビュー用動画

両ファイルの同じ作品を編集します。プロジェクト内に assets フォルダを作り、画像と動画を保存してください。

```html
<div class="empty-media" data-preview="assets/messy-world-preview.mp4" aria-hidden="true">
  <img src="assets/messy-world.webp" alt="">
</div>
```

動画はMP4（H.264）、16:9、5〜10秒程度の軽いファイルを推奨します。カーソルを合わせると無音で最大5秒再生し、離すか再生が終わると静止画に戻ります。キーボードでカードにフォーカスした場合も再生します。スマートフォンはタップすると詳細ページへ移動します。動きを減らす設定では自動再生しません。

`data-preview=""` のままなら動画は読み込みません。動画を設定するまで再生はありません。

## 作品詳細：projects/*.html

- 正式な作品タイトル、画像
- 作品ごとの開発環境（現在の記載内容を確認・修正）
- 開発期間、担当、制作人数
- 作品概要、実装・工夫

画像のパスは詳細ページでは `../assets/画像名.webp` としてください。資料URL欄はありません。

## 確認・公開

HTMLを保存してブラウザを再読み込みします。GitHub Pagesへ反映するにはコミットとプッシュが必要です。このチャットで変更を依頼した場合は、確認後に毎回コミット・プッシュします。
